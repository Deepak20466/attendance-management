# Agents & Architecture Overview

## Project Architecture & Configuration
This repository implements a production-ready Attendance Management System comprising:
1. **Backend**: FastAPI (Python) web application with PostgreSQL database managed via Alembic migrations.
2. **Frontend**: React JS admin dashboard and coach web UI.
3. **Mobile**: Flutter cross-platform mobile application supporting both Admin and Coach roles.

## Verification & Status of Requested Mobile Features

All requested changes have been fully implemented across the Mobile App (Flutter) as well as the supporting FastAPI Backend and React Dashboard:

### (a) IN ADMIN DASHBOARD (Mobile App)
1. **Students Section**:
   - Activity dropdown filter added to filter students by activity (Dance, Yoga, Other Activities).
   - Display of student activity badges in list items.
2. **Fees Section**:
   - Live search input added to easily find students while generating fee receipts.
   - Product Amount field integrated into receipt generation.
   - Total amount calculated and rendered alongside fee receipts (base fee + product amount).
3. **Reports Section**:
   - Month selection enabled (including viewing previous month details).
   - PDF export buttons generated for Student Attendance, Activity-wise Attendance, and Activity-wise Revenue.
4. **Student Attendance & Activity Revenue**:
   - Total/Overall revenue view incorporated into the Attendance / Reports tabs with PDF export support.
5. **Sessions Section**:
   - Session roster and class views updated so Admin can view uploaded coach photos after session completion.

### (b) IN COACH DASHBOARD (Mobile App)
1. **Fees Section**:
   - Date picker added allowing fee receipts to be generated by exact billing date (e.g., 10th September) in addition to month/year.
   - Student contact numbers restored and visible across all student rosters.
2. **Session Photos**:
   - Session completion form in Coach Dashboard enables uploading session photos directly to the backend.
   - Uploaded session photos immediately accessible to Admin in the Admin Dashboard.

## Mobile Login Responsiveness Update
- Login allows time for the production backend to wake from an idle Render free-tier instance,
  then shows a clear retry message instead of waiting indefinitely.
- Other API requests have bounded timeouts and display actionable errors.
- Admin and Coach dashboard shells render while their initial data loads, so a successful login
  does not remain blocked behind dashboard requests.
- Verified with the live health endpoint, which responded in 43.66 seconds during a cold start.
- Android release APKs built successfully for armeabi-v7a, arm64-v8a, and x86_64.

## Physical Android Login Hotfix
- The mobile default API URL is production (`https://vimj-backend.onrender.com`) on
  Android/iOS devices; local development can still override it with `API_BASE_URL`.
- Login exceptions now surface a useful connection/error message instead of the generic
  “Something went wrong” text.

## Product Name in Mobile Fees
- Admin and Coach fee forms now accept an optional product name alongside product amount.
- Product names are stored with fee records and coach receipts, shown in both dashboards,
  and included in generated receipt PDFs.

## Admin Dashboard Revenue Periods
- The Admin Dashboard revenue card now supports current month, a custom month, yearly,
  and overall collected revenue totals, including fee and product revenue breakdowns.

## Admin Dashboard Visual Polish
- Dashboard cards use consistent spacing, fixed label areas, responsive value sizing, and
  wrapped revenue breakdowns for professional alignment on mobile screens.
